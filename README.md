# Data Structures and Algorithms exercises

This repository will be a colection of exercises inspired by the different courses i do on the subject. All of the following exercises will be developed without any kind of help from AI, making it easier to learn from the different complications I encounter throughout the process.

## Linked Lists

For this exercise I have taken inspiration from the course from SimplyLearn "Basics of Data Structures and Algorithms", in which the professor uses different snippets of code to explain how to program linked lists. What I did was skip all of this demonstrations just to program the code myself, which is what can be found in __linked_lists.cpp__.

All of the work involving pointers was pretty difficult due to the lack of use I've given them throughout my studies, therefore making this exercise perfect to train them.
